PROPOSAL 2
URBANGEAR SPORTS & LIFESTYLE

ORGANISATION OVERVIEW

URBANGEAR SPORTS & LIFESTYLE is a local retail store selling affordable sports clothing, footwear, bags and basic fitness accessories. The store aims to make sports products accessible to students, beginners and local sports teams. Its mission is to provide quality sports products at reasonable prices with friendly service. Its vision is to become a trusted local sports retailer with a convenient online presence. The target audience being students, amateur athletes, parents, school teams and fitness enthusiasts.
Website Goals and Objectives
The website will increase the stores online visibility and help customers view products before visiting the shop. The objectives are to display products clearly, promote specials, generate customer enquiries and make it easier for customers to locate the store. KPI’s will include website visits, product-page views, contact enquiries, clicks on the store location information and online order requests.
Current Website Analysis
URBANGEAR has no existing website to evaluate. The proposed solution will focus on reducing common retail problems such as customers not knowing what products available, unclear prices and difficulty finding contact information.
Proposed Website Features and Functionality 
The website will contain Home, About, Products, Special Offers, Size Guide and Contact pages. Products will be grouped into categories such as clothing, footwear and accessories. Each product card will show an image, name, short description and price. Customers can use a simple enquiry form to request a product or ask about availability. JavaScript will provide basic form validation, category filtering and an image gallery. The website will not process real payments in the first version.

Design and User Experience
The design will use a modern black, white and orange colour palette to create an energetic sports feel. A clean sans-serif font will make product information easy to read. The homepage will feature promotional banners and clear calls to action such as “View Products” and “Contact Us”. The layout will be responsive so that customers can browse using phones, tablets or computers. Product images, consistent spacing and simple navigation will improve the user experience. Low-fidelity wireframes will be created before coding.
